# Craft

## Overview

Craft is a simple image gallery application with a lightbox feature, built using Astro. It provides a minimalistic and efficient way to showcase images with an elegant lightbox effect for better user experience. This project is ideal for developers looking to integrate a lightweight gallery solution into their Astro-based web applications.

## Features

- **Image Gallery**: Display a collection of images in a grid format.
- **Lightbox**: Click on any image to view it in a larger format with a lightbox overlay.
- **Responsive Design**: Optimized for various screen sizes using Tailwind CSS.
- **Alpine.js Integration**: Enhance interactivity with Alpine.js.
